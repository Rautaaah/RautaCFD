RautaObfuscator.exe
RautaObfuscator
protect your code inside a PIN-locked Safe
🔒 No Safe

📖 RautaObfuscator tutorial

  1. Choose a language from the language dropdown.
  2. Enter a PIN and click Create Safe.
  3. Type your code into the editor. RautaObfuscator uses Monaco Editor, so you get syntax highlighting and autocomplete.
  4. For example, select Luau and type: pri
  5. Monaco will suggest: print
  6. Press Enter or click the suggestion to insert it.
  7. Click Obfuscate to generate the output.
  8. Your code and generated output are saved inside your browser's encrypted local Safe.
  9. Click Lock Safe when you're finished.

💡 Tip: press Ctrl + Space to manually open autocomplete.

The Safe is stored locally in your browser. Clearing browser storage can remove it.
